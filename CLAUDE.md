# Project instructions

## Backend changes (enkepos)

Never edit the backend (`enkepos/`) directly. When an issue needs a backend change:

1. Explain what to change and why (file, line, root cause).
2. Give a ready-to-send message for the backend developer, 4–5 lines, plain text.

The user forwards that message to the backend developer. Only edit backend code if the user explicitly asks.

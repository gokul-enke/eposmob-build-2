# Billing Page Keyboard Shortcuts (Standard)

File scope: `lib/screens/billing/billing_page.dart`

## Global

- `Ctrl + H`: Open keyboard shortcuts help dialog
- `Ctrl + K`: Toggle virtual keyboard
- `Ctrl + D`: Focus cart table
- `D`: Open cash drawer
- `Ctrl + A`: Focus barcode field (when barcode sales is enabled)
- `Ctrl + S`: Focus search product field

## Cart

These work when cart table focus is active.

- `Arrow Up / Arrow Down`: Move focused cart row
- `Arrow Left / Arrow Right`: Move focused cart cell/action
- `Enter` or `Space`: Activate focused cart action/cell
- `Delete`: Remove focused cart item
- `+ / -`: Increase or decrease focused cart item quantity
- `Ctrl + U`: Focus unit edit for selected cart row
- `Ctrl + Q`: Focus quantity edit for selected cart row
- `Ctrl + P`: Focus price edit for selected cart row
- `H`: Open purchase history for focused cart row (when supported)

## Billing

- `F1`: Clear cart
- `F2`: Open checkout confirm
- `F3`: Open checkout at Customer step
- `F4`: Open checkout at Delivery step
- `F5`: Open checkout at Payment step
- `F6`: Open checkout confirm and print
- `F7`: Create new order
- `F8`: Open checkout save mode
- `F9`: Open checkout save and print mode
- `F10`: Open checkout at Discount step
- `F11`: Legacy/reserved behavior
- `F12`: Activate sidebar keyboard mode

## Navigation

- `Tab` and `Shift + Tab`: Move through ordered focus targets
- `Esc`: Exit sidebar keyboard mode (if active) and return focus to product entry
- `Arrow Keys`: Used in focused lists/grids/rows

## Checkout Modal

- `F3`: Customer step
- `F4`: Delivery step
- `F10`: Discount step
- `F5`: Payment step
- `F2`: Confirm order
- `F6`: Confirm and print
- `F8`: Save
- `F9`: Save and print
- `Esc`: Close modal

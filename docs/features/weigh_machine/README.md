# Weigh Machine

Documentation for the Weigh Machine feature: choosing products and saving the
`PLU.csv` file a weigh machine (scale) imports.

## Files

- `FEATURE_SPEC.md` — UI behavior and frontend rules.
- `TODO.md` — open work.
- `CHANGELOG.md` — short history of changes.

## Sources of truth

- UI behavior: `FEATURE_SPEC.md`
- CSV format: `lib/features/weigh_machine/domain/plu_csv.dart`
- Flutter code: `lib/features/weigh_machine/`
- Tests: `test/features/weigh_machine/`
